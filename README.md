# 속지 말고 잡아라! 팩트체크 — 1~3일차 웹앱

교사가 넘기면 학생 휴대폰·태블릿 화면이 따라오는 수업 웹앱입니다. TV가 작아도 학생은 자기 기기에서 슬라이드를 읽고, 슬라이드 사이의 게임·활동 화면에 바로 참여합니다.

## 파일
- `teacher.html` 교사 진행 화면 (비밀번호: config.js의 TEACHER_PIN, 기본 1234)
- `student.html` 학생 화면 (QR로 접속, 이름 입력)
- `index.html` 미리보기 (교사 1 + 학생 2 화면을 한 페이지에서 시험)
- `data.js` 수업 내용(슬라이드 문구, 퀴즈, 문장 구분, 연대기 카드, 상 이름) — 여기만 고치면 내용이 바뀝니다
- `config.js` Firebase 설정, 방 코드, 비밀번호

## 실제 수업 전에
1. Firebase 콘솔에서 Realtime Database를 만들고 config.js에 설정값을 붙여 넣습니다. (비워 두면 같은 브라우저 탭끼리만 연결되는 데모 모드)
2. 폴더 전체를 GitHub Pages 등에 올립니다.
3. 교사 화면을 열고 QR(Q 키)을 보여 줍니다. 반마다 `teacher.html?room=3-1`처럼 방 코드를 바꾸면 데이터가 섞이지 않습니다.

## 활동 화면 (★)
미니 설문 · O/X 퀴즈 10문항(+결과) · AI 얼굴 점수 입력 · 뉴스 문장 구분하기(R로 정답 공개) · 팩트체크 연대기 순서 게임(+정답·순위) · 출품하기(이미지 첨부, 자동 압축) · 출품작 둘러보기 · 투표(상 3개, 내 카드 투표 불가) · 시상

## 단축키 (교사)
→ / Space 다음 · ← 이전 · R 정답 공개 · Q QR 크게 · P 진행 패널 숨기기(TV용)

## 학생 화면
- ☰ 목차: 1일차는 화면 제목까지 자세히, 2·3일차는 큰 제목만 보입니다.
- 지난 화면을 눌러 다시 볼 수 있고, ‘선생님 화면으로’를 누르면 돌아옵니다.

## 부적절한 출품작
교사 화면 ‘출품하기’ 또는 ‘둘러보기’에서 카드를 눌러 ‘이 카드 숨기기’ → 갤러리·투표·시상에서 빠집니다.

## 수업 기록
교사 화면 오른쪽 패널의 ‘참여 현황 · 출품 카드 모음 (PDF)’ 버튼 → `record.html`이 열려요. 학생별 웹앱 참여 횟수(최대 23회) 표, CSV 받기, 출품 카드 전체(받은 표 포함) 인쇄·PDF 저장이 됩니다.

## 2일차 (4교시)
교사 화면 오른쪽 패널 맨 위의 **1일차 / 2일차** 버튼으로 수업 날짜를 바꿔요. 학생 화면도 그 날짜의 첫 화면으로 바뀌고, 목차는 그 날짜만 자세히 보여요.
- 1교시 어제 복습: 단어 구름 · 어제 수상작 · 유명한 가짜뉴스(검색 링크) · 특징 8가지 퀴즈
- 1~2교시 검색 수사대: 팩트수사대 인턴 시험 · 수사 1(광역자치단체 통계) · 수사 2(렌즈로 〈갈릴리 호수의 폭풍〉, 도난 사건) · 학생 이미지 퀴즈 출제·풀이·결과 · 검색 연산자 7개 미션 · 논문 수사 · 프롬프트 어휘 퀴즈
- 3교시 생성형 AI: 기존 AI와 차이 · 먼저 그려 보기 · 프롬프트 5요소 · 다음 말 맞히기 · AI 거짓말 사례 · 환각 · 이미지 생성 원리 · AI 그림+제미나이 검증 결과 올리기 · 갤러리
- 4교시 가짜뉴스 만들기: 게임 체험(Bad News, 사실 혹은 거짓) · 가짜 게시물 만들기(🔒 비공개 정답 칸) · 전시장(😱 반응)
- R 키 정답 공개: 수사 1(사실/거짓), 빈칸 문제
- 응답 초기화: ‘2일차 응답’, ‘2일차 올린 것’ 버튼
- 수업 기록 페이지에 2일차 활동 수, 가짜 게시물(비공개 칸 포함), AI 그림이 추가돼요.

## 3일차 (4교시)
오른쪽 패널의 **3일차** 버튼으로 바꿔요.
- 1교시 복습·검색 보충: 단어 구름 · 복습 퀴즈 5 · 우리가 만든 결과물 · 구글 고급검색 미션 6 · 네이버 뉴스 라이브러리 미션(+전시)
- 2교시 가짜 뉴스 사이트: 구글 사이트 vs 크롬 퀴즈 · 메모장 실습 · HTML/CSS/JS 코드 실습(미션 6, 자동 확인) · 제미나이 프롬프트(복사 버튼) · **사이트 올리기**(코드 붙여넣기 또는 .html 파일) · 사이트 전시장(😱 속을 뻔)
- 3교시 팩트체크 보고서: 워크북 결과지 양식 그대로 + 판정 6단계 · 제출하면 교사 화면에 모이고, 학생은 **PDF 받기 / 인쇄 화면 / 글 복사**
- 4교시: 포스터·PPT·카드뉴스 비교 · 보고서→카드뉴스 과정 · **카드뉴스 올리기(그림 최대 8장)** · 투표(1인 1표) · 베스트 발표(R) · 사후 설문 · 카훗 · **시상(R)**: 웹앱 참여왕(3일 참여 순위에서 교사가 1명 선택) + 워크시트 성실상(교사가 2명 선택) + 베스트 카드뉴스(투표 1위)

### 학생 사이트는 어떻게 공개되나요?
학생이 올린 HTML 코드는 Firebase `factcheck_d1/방/blob/site/학생id`에 저장되고, `site.html?room=3-2&sid=…`가 그 코드를 불러와 보여 줘요(GitHub에 파일을 쓰지 않음 → 토큰을 앱에 넣을 필요가 없어요).
- 사이트는 `sandbox="allow-scripts"` 틀 안에서만 돌아가서 수업 앱의 데이터·로그인에 접근할 수 없고, 입력 양식 전송도 막혀 있어요.
- 화면 위 경고 띠와 오른쪽 아래 ‘수업용 가짜 사이트’ 표시가 항상 붙어요. 교사는 사이트를 열고 ‘이 사이트 숨기기’로 내릴 수 있어요.
- 수업이 끝나면 오른쪽 패널 ‘3일차 응답 · 올린 것 전체’로 지우거나, Firebase 규칙을 닫아 주세요.

### 수업 기록
`record.html`에 3일 참여 종합(시상 참고), 가짜 사이트(🔒 정답 포함, 주소 링크), 카드뉴스 득표, 팩트체크 보고서 전체(한 장씩)가 추가됐어요. 인쇄 → PDF 저장.
